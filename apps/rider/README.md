# ⚠️ 已合并进单小程序，本目录仅作参考

原来这里是**独立的骑手端 uni-app 工程**。

现在产品决策改成「**一个小程序，进去选身份**」，骑手页面已经搬进：

```
apps/user/pages/rider/          ← 新的位置（在用）
  ├── center.vue                骑手中心
  ├── workbench.vue             抢单大厅 / 我的任务
  ├── detail.vue                任务详情（取件/送达）
  ├── wallet.vue                收入与提现
  └── apply.vue                 申请成为骑手
```

数据层在 `apps/user/store/rider.js`（Vuex 命名空间 `rider`），入口在「我的 → 🛵 骑手中心」。

**为什么合并**：只有一个小程序 appid，两个工程分别上线会互相覆盖；学生既是用户也可能是骑手，切身份比装两个 App 更自然。信息隔离不受影响——仍然由服务端的 `xyyx-user` / `xyyx-rider` 两个云对象 + 字段裁剪保证。

本目录保留仅作历史参考，**不再维护**。如果以后要拆回两个小程序（需要再申请一个 appid），可以把它捡回来。
