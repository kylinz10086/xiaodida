```
1095
```

1. 法定留存。《电子商务法》要求商品和服务信息、交易信息**保存时间自交易完成之日起不少于三年**，90 天覆盖不了售后、退款、投诉的举证期。

个人信息的保存期限仍是"实现处理目的所必要的最短时间"，1095 天是**上限性承诺**，不是每类数据都存 3 年。
