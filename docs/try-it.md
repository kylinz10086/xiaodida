# 体验指南（10 分钟跑通一单）

> 目标：让你在同一个小程序里，先当**用户**发一单，再切**骑手**接单送达，最后回用户确认收货，看到钱进账。

前置：云端已经部署好（`xyyx-user` / `xyyx-rider` / `xyyx-pay` / `xyyx-cron` 四个云对象都在 `env-00jy72ju8b4z`）。

---

## 一、把工程跑起来

### 方式 A：用 HBuilderX 运行（推荐）

1. HBuilderX 打开 `F:\xiaodida\apps\user`
2. 顶部菜单 **运行 → 运行到小程序模拟器 → 微信开发者工具**
3. 微信开发者工具会自动打开并加载

### 方式 B：直接导入编译产物

微信开发者工具 → **导入项目** → 选：

```
F:\xiaodida\apps\user\unpackage\dist\dev\mp-weixin
```

> 首次打开前，先确认开发者工具的 **服务端口** 是开的（见第五节）。

## 二、先当用户，发一单

1. 进入小程序，首次会弹**用户协议** → 点「同意并继续」
2. 点 **右上角「我的」** → 登录（微信一键登录 / 账号密码）
3. 回 **首页** → 点「代取快递」大卡片
4. 填：
   - 任务标题：`东门驿站取个快递`（至少 4 个字）
   - 悬赏金额：`5`
   - 手机号：填你的真实号（骑手要用它联系你）
   - 取件地点 / 送达地点：随便填，比如 `东门菜鸟驿站` → `3号宿舍楼`
5. 点 **发布任务**
6. 会弹支付：
   - 现在**没有配商户证书**，走的是 **mock 支付** → 直接点确认，视为支付成功
   - 页面会提示「下单成功」
7. 去 **订单** Tab，能看到这单状态是「待接单」

> 此时后台已经发生：订单落库（`pay_status=paid`）+ 一条 `escrow_in` 托管流水（钱在平台手里，还没给骑手）。

---

## 三、切成骑手身份

1. **我的** → 点 **🛵 骑手中心**
2. 第一次进来会显示「未认证」→ 点 **申请成为骑手**
3. 填真实姓名 / 学号 / 手机号 → 勾选协议 → 提交
4. 状态变成「审核中」

**开通审核**（现在还没有管理后台，手工放行一次）：

1. 打开 <https://unicloud.dcloud.net.cn/> → 选中空间 `env-00jy72ju8b4z`
2. 左侧 **云数据库** → 集合 `xyyx-users`
3. 找到你那条记录（`_id` 就是你的用户 id）→ 编辑 → 把 `rider_status` 改成 `2` → 保存
4. 回小程序，进 **骑手中心** → 下拉刷新，状态应该变成「已认证骑手」

---

## 四、接单 → 送达 → 确认收货

1. 骑手中心 → **抢单大厅** → 能看到刚才自己发的那单
   - ⚠️ 注意：**不能接自己发布的单**（服务端会拒），所以最好是**用另一个微信账号**当骑手
   - 如果只有一个账号，就找同学用他手机发一单，你来接
2. 点 **抢单** → 提示「抢单成功」（这里用的是状态 CAS，两个人同时抢只有一个能成）
3. 进 **我的任务** → 点这单：
   - 先点 **已取件**
   - 再点 **已送达**
   - 此时能看到 **脱敏手机号** `138****1234`（接单前是完全看不到的）
4. 切回**用户身份**（我的 → 订单 → 这单）→ 点 **确认收货**
5. 再看骑手中心 → **我的收入**：
   - 余额 +9 元
   - 明细里有一条「完成订单收入（已扣平台佣金 1 元）」

> 到这里，`escrow_in → income + commission + escrow_out` 四条流水就齐了，钱从托管到了骑手钱包，平台留下 10%。

## 五、开发者工具「服务端口」怎么开

CLI / 自动化要用它，不开的话我这边没法帮你出预览二维码。

1. 打开 **微信开发者工具**
2. 右上角 **齿轮图标（设置）**
3. 左侧选 **安全设置**
4. 找到 **服务端口** → 打开开关
5. 关掉设置窗口即可

验证：在 HBuilderX/终端执行下面这条，能返回 JSON 就说明通了：

```powershell
& "F:\微信web开发者工具\cli.bat" islogin
# 期望输出类似：{"login":true}
```

## 六、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 抢单提示「你还不是骑手」 | `rider_status` 不是 2，见第三节 |
| 抢单提示「不能接自己发布的单」 | 换个账号当骑手 |
| 支付弹窗直接失败 | 没配商户证书时应该走 mock；如果弹了微信支付说明 `pay-config.js` 被配上了 |
| 页面一直转圈/报「云端未就绪」 | 云对象没部署成功，重跑 `tools\scripts\deploy-cloud.ps1` |
| 订单在大厅里看不到 | 只有 `pay_status=paid` 才会进大厅，确认支付那步真的成功了 |
| 骑手看不到手机号 | 这是**故意的**：接单前不给，接单后只给脱敏号 |

## 八、第一次跑不起来？先看域名校验

uniCloud 的请求域名是：

```
https://env-00jy72ju8b4z.api-hz.cloudbasefunction.cn
```

**开发者工具里**（本地调试）：

1. 右上角 **详情**
2. **本地设置**
3. 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**

不勾的话所有云对象调用都会返回 `[xyyx-user]: request:fail`。

**真机 / 上线**（必须做）：

微信公众平台 → 开发管理 → 开发设置 → **服务器域名** → request 合法域名里加上
`https://env-00jy72ju8b4z.api-hz.cloudbasefunction.cn`，否则真机上一样调不通。

> 顺带说明：编译产物 `unpackage/` 里会内嵌该空间的 accessKey/secretKey（uniCloud 客户端 SDK 的正常设计），
> 所以 `unpackage/` 必须在 `.gitignore` 里，不能提交。
