## 三、代码分层

| 层 | 位置 | 职责 | 不许做什么 |
| --- | --- | --- | --- |
| 页面 | `pages/**/*.vue` | 展示与交互 | 不写业务规则、不算钱 |
| 状态 | `store/index.js` | 调云对象、映射视图字段 | 不直接拼接口参数以外的逻辑 |
| 云对象 | `cloudfunctions/xyyx-*` | 鉴权 → 校验 → 业务 → 裁剪 | 不直接信任客户端入参 |
| 公共模块 | `common/xyyx-common` | 鉴权、裁剪、记账 | 不含具体业务分支 |
| 数据层 | `database/*.schema.json` | 字段与权限 | 不对客户端开放 |

## 四、关键设计决策

| 决策 | 原因 |
| --- | --- |
| 后端只放 `apps/user` 一处 | uniCloud 的云函数必须挂在某个 uni-app 工程下才能被 HBuilderX 上传；骑手端靠 `_spaceID` 指向同一空间，运行时解析 |
| 两个云对象而不是一个 | 「角色能调什么」由调用哪个对象决定，比在每个方法里 if 判断更不容易漏 |
| 金额用整数分 | 浮点累加会漂移；微信支付也只收分 |
| 字段裁剪放服务端 | 前端藏字段等于没藏，抓包就破 |
| mock 支付 | 没有商户证书也能把流程跑通；配置真实支付后 mock 自动禁用 |
| 记账带 idempotency_key | 支付回调、重复点击、网络重试都可能重复触发 |

## 五、扩展点

| 想加什么 | 改哪里 |
| --- | --- |
| 新任务类型 | `TASK_TYPE` 常量 + 页面筛选项 + schema enum |
| 改抽佣比例 | `xyyx-common` 的 `COMMISSION_RATE`（记得更新 rule.md 第 6 节） |
